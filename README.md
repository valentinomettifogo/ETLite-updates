# ETLite Updates

Update packages for the [ETLite](https://github.com/valentinomettifogo/ETLite-v3) desktop application. This repository is used exclusively as a public endpoint from which the app downloads its latest versions.

## Information

- This repository does not contain any source code of the application.
- All files are automatically generated by the ETLite-v3 build pipeline (`update-cli` module).
- The folder and file structure is defined by the internal auto-update system — do not edit it manually.

## Note

This repository is public solely to allow downloading update packages. It is not intended for external use or as project documentation.
