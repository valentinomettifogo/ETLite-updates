# CLAUDE.md — ETLite Updates

## Project overview

This is a distribution-only repository. It contains no source code — it is a public endpoint that the [ETLite-v3](https://github.com/valentinomettifogo/ETLite-v3) desktop app polls and downloads updates from.

## Conventions

- Never manually create, edit, or delete files in this repo. All content is auto-generated by the ETLite-v3 build pipeline (`update-cli` module / `task publish`).
- The folder and file structure is load-bearing for the auto-update system — changing it breaks update detection in the live app.
- There is nothing to develop, test, or build here.
